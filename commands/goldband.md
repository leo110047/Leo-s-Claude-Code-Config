# Goldband capability adapter

Use `/goldband <capability> <action>`. Resolve the installed `goldband` runtime,
then follow its root `SKILL.md`. The manifest-generated capability menu and
`workflows/<capability>/<action>.workflow.md` documents are authoritative.

Do not enumerate capabilities here, accept historical workflow names, create
aliases, or redirect unknown input. An empty invocation shows the root menu.
